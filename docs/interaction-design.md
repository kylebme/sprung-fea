# BetterSim interaction design

## Product contract
A person with a STEP solid and basic engineering intent should reach an inspectable, reproducible linear static result without learning a solver deck. Every displayed result must come from CalculiX. No synthetic result fallback. Version one supports one connected solid, isotropic elastic material, face supports, distributed total vector force, normal pressure, and gravity. Millimetres, newtons, megapascals are the explicit working units. STEP units are normalized by OpenCASCADE to millimetres; the import inspector displays dimensions before setup.

## Research and interpretation
Reviewed the official SOLIDWORKS static analysis workflow, study tree, selection methods, uniform force editor, restraints, meshing options, convergence guidance, deformation plots, and linear static assumptions. The design below is an independent interpretation, not a reproduction of its visual layout, assets, or text.

- [Static workflow](https://help.solidworks.com/2021/english/solidworks/cworks/t_Performing_Static_Analysis.htm): studies collect material, restraints, loads, mesh, then results. This dependency order reduces missing inputs. Preserve it as a checklist, without requiring right-click discovery.
- [Study tree](https://help.solidworks.com/2022/english/SolidWorks/cworks/c_simulation_study_tree_interface.htm): input and output share an inspectable hierarchy. Preserve named, editable conditions and visible status; avoid empty assembly folders in a single-part product.
- [Selection](https://help.solidworks.com/2022/english/SolidWorks/acadhelp/c_Selection_Methods.htm): hover preview, preselection, and selection during a tool are useful. Restrict v1 to faces so clicks have one meaning. A face list with type, area, center, and hover highlight makes small/hidden faces reachable without arcane filters.
- [Uniform force](https://help.solidworks.com/2019/english/SolidWorks/cworks/c_defining_uniform_force.htm): total versus per-item is consequential. Use total force across all selected faces, distributed by surface integration. Label units and direction; preview arrows before commit. Do not multiply force silently when adding a face.
- [Restraints](https://help.solidworks.com/2021/English/SolidWorks/cworks/IDC_HELP_RESTRAINTS.htm): physical descriptions are clearer than solver constraints. Default to "Fixed" with all translations blocked. Advanced directional supports expose global X/Y/Z with explicit blocked/free states. Verify all six rigid motions are restrained; never conceal instability with soft springs.
- [Mesh options](https://help.solidworks.com/2022/english/SolidWorks/cworks/c_meshing_options.htm): curved geometry and bending benefit from quadratic tetrahedra. Use C3D10 always, curvature-aware meshing, three understandable detail presets, and optional explicit size. Mesh remains inspectable, and a finer repeat can quantify changes.
- [Convergence](https://blogs.solidworks.com/products/solidworks/how-good-is-your-mesh-anyway/): a successful solve does not imply sufficient discretization. Offer a refinement comparison, retain prior results, and distinguish global displacement convergence from peak stress at a singularity.
- [Deformation plots](https://help.solidworks.com/2015/English/SolidWorks/cworks/idc_help_preference_plot.htm): automatic magnification helps comprehension but can mislead. Display the exact multiplier adjacent to the model; provide true scale and undeformed choices.
- [Linear assumptions](https://help.solidworks.com/2021/english/SolidWorks/cosmosxpresshelp/c_Assumptions_of_Linear_Static_Analysis.htm): linear elastic, slowly applied load, small deformation. Explain scope in the start screen and interpretation panel; highlight yield exceedance and large displacement rather than implying a pass/fail certification.

## Interaction specification (decided before UI implementation)
One workspace: a study tree and face list on the left, the part at the center, and an inspector for the selected tree item on the right. A stable title bar owns document operations, undo, theme, and Solve. The center is reserved for geometry, selection guidance, a compact camera toolbar, the result legend, and a collapsed console for job output and solver checks. A status bar reports dimensions, hovered face, and the current operation.

1. Start with an import drop target and two real STEP examples (beam and perforated bracket). No fake result dashboard.
2. Import builds a surface preview through the same CAD kernel used for volume meshing. Show dimensions, volume, face count, and units. Reject assemblies and surface-only STEP files with an actionable message.
3. Click Material, choose a preset or enter custom elastic modulus, Poisson ratio, density, and optional yield strength. Show engineering values, not unexplained solver fields.
4. Click Supports or Loads. Select geometry by clicking or from an accessible face list. Selections persist while changing tool settings. Save commits a named condition; cancel discards a draft. Existing conditions can be edited and removed. Face highlighting and physical arrows explain applied inputs.
5. Mesh density uses Coarse, Medium, Fine, with an explicit element size field. The recommended size considers the smallest part dimension. Preview meshing is distinct from Solve, but Solve meshes automatically when needed.
6. Run readiness includes a material, supported faces, a nonzero load, finite data, valid face references, and full rigid-motion restraint. Show missing requirements inline. Busy state has stage progress, elapsed time, and cancellation. Errors preserve the study and expose diagnostic details.
7. Results show stress, movement, and yield margin with units and selectable plots. Clicking a surface probes the nearest result node, showing location and values. Exact deformation magnification is visible. Offer a finer solve with percentage changes, CSV export, solver deck/log export, screenshot, and portable project save/open.
8. Editing any physical input invalidates results immediately. Editing mesh invalidates mesh and results. Camera, selection, plot, and deformation display never invalidate physics.

## Architecture and extension seams
Electron is a sandboxed shell around a Vite/React renderer. Three.js handles CAD-face meshes and result contours. A loopback Node service owns file intake, project serialization and cancellable job processes. Python/Gmsh owns STEP topology and quadratic volume meshing. A CalculiX adapter writes decks and parses FRD output. Geometry IDs are scoped to the exact STEP content hash; projects embed that geometry, avoiding false persistent naming across revised CAD files. Solver adapters can later implement other study types without coupling renderer controls to deck syntax.

## Acceptance evidence
Subsystem tests solve real imported STEP solids, check analytical axial extension and cantilever displacement, force conservation, rigid-motion rejection, pressure, quadratic connectivity, invalid input handling, and refinement. End-to-end tests import, select faces, edit material, solve, inspect/probe, invalidate results, and reopen portable projects. macOS Electron launch and packaged app are exercised separately.
